# Sistema de Gestión de Productos

Aplicación web para la administración de productos mediante operaciones CRUD, desarrollada con React y tecnologías web modernas.

## Descripción

Este proyecto consiste en una aplicación de gestión de productos que permite registrar, consultar, actualizar y eliminar información desde una interfaz web responsive.

El proyecto fue desarrollado aplicando una arquitectura basada en componentes de React, separación de responsabilidades y una interfaz enfocada en claridad, usabilidad y adaptación a diferentes dispositivos.

## Historial del proyecto

El desarrollo de esta aplicación comenzó originalmente en julio/2026 y se trabajó de forma progresiva durante varios meses.

Debido a la pérdida del repositorio original, el proyecto fue reconstruido y publicado nuevamente en este repositorio. El código actual corresponde al estado funcional alcanzado durante el desarrollo, mientras que el historial Git visible en este repositorio comienza a partir de su reconstrucción.

Las funcionalidades, decisiones de diseño y estructura del proyecto reflejan el proceso de desarrollo realizado originalmente.

## Características

- Crear nuevos productos.
- Consultar productos registrados.
- Actualizar información existente.
- Eliminar productos.
- Validación básica de los datos del formulario.
- Actualización dinámica de la interfaz.
- Diseño responsive para escritorio, tablet y móvil.
- Estados visuales para listas sin registros.
- Interacciones y estilos personalizados para mejorar la experiencia de usuario.
